# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/1Xe6jVlRGrNwmEzON0fzgDI_T7dsoTX0d

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

### API Configuration
The app is configured to use ModelScope API with Qwen models. The API configuration is defined in `vite.config.ts`.
